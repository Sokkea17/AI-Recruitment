# Telegram Recruitment Automation Bot & HR Dashboard

A production-ready Telegram Recruitment Assistant paired with a modern HR Web Dashboard built with FastAPI, python-telegram-bot (v20+ async), and SQLAlchemy 2.0.

## Overview
This platform automates:
1. HR Job Description (JD) parsing (PDF, DOCX, DOC, TXT)
2. Interactive candidate vacancy browsing and CV submission via Telegram
3. Candidate contact detail verification and duplicate application management
4. Real-time HR Telegram alerts with candidate reports and CV attachment
5. Full-featured HR Web Dashboard for vacancy and candidate lifecycle management

## Tech Stack
- Backend: FastAPI, Python 3.9+
- Database: SQLAlchemy 2.0 Async + SQLite (Dev) / PostgreSQL (Prod)
- Telegram Bot: python-telegram-bot v20+
- Document Extraction: pypdf, python-docx
